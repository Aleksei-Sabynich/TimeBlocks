# Timeblocks — Интерактивный исторический таймлайн

Динамический веб-компонент для визуализации временных отрезков и ключевых событий.
Проект реализован на **React 19** с использованием мощных анимаций **GSAP** и интерактивных слайдеров **Swiper**.

## ✨ Особенности
*   **Плавная навигация:** Анимированное переключение между временными периодами.
*   **Динамические данные:** При смене периода автоматически обновляются числовые значения и контент.
*   **Интерактивный слайдер:** Детальный обзор событий для каждого отрезка с поддержкой touch-событий.
*   **Современный стек:** Типизация на TypeScript и сборка через Webpack.

## 🛠 Технологический стек
*   **Библиотеки:** React 19, GSAP (анимации), Swiper (слайдеры).
*   **Стили:** SASS (SCSS), clsx.
*   **Инструменты:** Webpack 5, TypeScript.

## 🚀 Быстрый запуск (Инструкция) 
### 1. Подготовка Убедитесь, что у вас установлена **Node.js** (версия 18.x или выше). Проверить: node -v. 
### 2. Клонирование и переход 
 Откройте терминал и выполните:
    bash
    git clone https://github.com/Aleksei-Sabynich/TimeBlocks.git
    cd timeblocks
### 3. Установка зависимостей
  Скачайте все необходимые библиотеки (создаст папку node_modules):
    bash
    npm install
### 4. Запуск проекта
  Запустите сервер для разработки:
    bash
    npm start
  Проект откроется по адресу: http://localhost:8080
### 5. Сборка для продакшена
  Для создания готовых оптимизированных файлов в папке dist:
    bash
    npm run build

### 📂 Команды в терминале (Bash)
    npm start — запуск «живого» сервера с автообновлением.
    npm run build — финальная сборка проекта.
    CTRL + C — остановить работающий сервер в терминале.
